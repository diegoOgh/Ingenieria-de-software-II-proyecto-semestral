# Sistema de Notificaciones por Correo

Este módulo permite enviar alertas automáticas al encargado de convivencia cada vez que se registra un nuevo caso de conflicto.

## Requisitos de instalación
Para que el sistema de correos funcione, es necesario instalar las librerías mediante Composer.

1. Abre tu terminal y ubícate en la carpeta del proyecto donde se encuentra el archivo `composer.json` (la carpeta `Formulario`):
```bash
   cd Formulario
```

2. Luego ejecuta el siguiente comando para descargar las dependencias necesarias:
```bash
   composer install
```
